تطبيق مؤسسي متكامل يعمل بمعمارية **Peer-to-Peer Mesh & Local-First** دون الحاجة إلى خادم مركزي أو اتصال بالإنترنت، مصمم للعمل على **Windows 7 (SP1)** و **Windows 10/11** و**Linux**، مع بوابة ويب وهاتف موحدة تدعم الحسابات الموزعة والتجوال بين الأجهزة (`PC Account Roaming`) عبر الشبكة المحلية.

---

## ما الجديد في TwinSync Pro v2.2.0

1. **إصلاح فحص وإصلاح جدار الحماية والشبكة لغير المسؤولين (`Windows Network Guard v2.2`):**
   - قراءة دقيقة لقواعد الجدار الناري مباشرة من سجل ويندوز (`HKLM\...\FirewallPolicy\FirewallRules`) باللغة الإنجليزية الموحدة حتى تحت صلاحيات المستخدم العادي (`asInvoker`) وبأي لغة نظام.
   - تمرير أوامر الإصلاح عبر PowerShell `-EncodedCommand` لضمان حفظ القواعد التي تحتوي مسافات (`TwinSync Pro LAN`, `TwinSync Pro Mesh TCP 41235`, `TwinSync Pro Portal TCP 41236`, `TwinSync Pro Discovery UDP 41234`) وتحويل جميع الشبكات الفيزيائية (`Wi-Fi` وكابل `Ethernet`) من `Public` إلى `Private` بضغطة زر واحدة مع عرض الاتصالات النشطة في الإعدادات.
2. **روابط QR تفاعلية لكل كرت شبكة وتصفية الكروت الافتراضية تلقائياً:**
   - تصنيف وتصفية كروت الشبكة الافتراضية تلقائياً (`VMware`, `VirtualBox`, `Docker`, `Hyper-V`, `WSL`) حتى لا يظهر عنوان غير قابل للوصول كرمز QR افتراضي.
   - توليد `qrDataUrl` مخصص لكل كرت شبكة (`Wi-Fi`, `كابل LAN / Ethernet`, `VPN`) في التبويبين (الربط السريع والبوابة الموحدة)، بحيث يكفي النقر على أي رابط في القائمة لتحديث رمز QR فوراً.
   - قسم جديد في الإعدادات **"إدارة كروت الشبكة وروابط QR"** للتحكم في إخفاء/إظهار أي كرت شبكة وتعيين الكرت الافتراضي (`Default / Pinned`).

## مزايا TwinSync Pro v2.1.0

1. **نسخة سطح المكتب الكاملة عبر المتصفح (`Full Desktop Web Edition`):**
   - توجيه تلقائي ذكي حسب نوع الجهاز: عند فتح رابط البوابة (`/?mode=portal`) من متصفح أي كمبيوتر أو لاب توب، يُفتح تلقائياً تطبيق سطح المكتب الكامل (`/desktop/`) بواجهة React الكاملة وتكامل مدير الملفات والصلاحيات وسلة المحذوفات والسحب والإفلات مع الحفاظ على خصوصية **Zero Footprint** (في الذاكرة فقط دون `localStorage` أو كوكيز)، بينما يُفتح الموبايل على واجهته اللمسية السريعة مع زر للتبديل بين الوضعين.
2. **توزيع وتحميل مثبّت الويندوز أوفلاين عبر الراوتر (`Offline LAN Distribution`):**
   - يحتفظ المثبّت بنسخة مخفية من نفسه داخل `C:\ProgramData\TwinSync_Vault\.installers\TwinSync-Pro-Setup.exe` تلقائياً عند التثبيت (مع زر إرفاق/تحديث `.exe` في الإعدادات).
   - تظهر بطاقة **"تحميل وتثبيت TwinSync Pro للويندوز"** في شاشة الدخول على الويب والشريط الجانبي لتحميل المثبّت مباشرة من أي جهاز على نفس الراوتر بدون إنترنت.
3. **اكتشاف Tailscale والاتصال المباشر عبر IP (`Cross-Subnet Discovery`):**
   - اكتشاف تلقائي لأقران **Tailscale** المتصلين وعبر بطاقة **"الاتصال المباشر عبر IP / Tailscale"** في الإعدادات لربط الأجهزة عبر الشبكات المختلفة التي لا يمر عبرها UDP Broadcast.
   - تصفية شريط "الأقران على الشبكة" السريع في تطبيق سطح المكتب وبوابة الويب ليعرض **المتصلين حالياً فقط (`online`)** سواء عبر التطبيق أو الويب، مع إمكانية حذف الأقران غير المتصلين من الإعدادات.
4. **تجهيز الشبكة وجدار الحماية تلقائياً على ويندوز (`Windows Network & Firewall Guard`):**
   - فتح المنافذ المطلوبة صراحةً (`UDP 41234`, `TCP 41235`, `TCP 41236`) وقواعد البرنامج عند التثبيت على جميع الشبكات (`profile=any`).
   - فحص صامت عند بدء التشغيل على ويندوز: إذا كانت الشبكة `Public` أو القواعد ناقصة يظهر تنبيه واضح للمستخدم لتحويل الشبكة إلى `Private` وفتح المنافذ بضغطة زر واحدة.
5. **تحسينات الواجهة وتلميح المتواجدين الذكي (`UI & Presence Fixes`):**
   - نقل تلميح المتواجدين في [FileManager.jsx](file:///home/ahmed/Desktop/DEV/localShare/src/renderer/components/FileManager.jsx) عبر `createPortal` بتموضع ذكي يمنع اقتصاصه أعلى الشاشة، مع شريط حالة مصغّر داخل البطاقات يوضح اسم الشخص الذي يعدّل/يعاين الملف مباشرة.
   - إصلاح تنسيق شاشات RTL ومنع التفاف النصوص، وإصلاح عرض شاشة المحادثات على بوابة الموبايل.

## مزايا الإصدار الأساسي TwinSync Pro v2.0.0

1. **الهوية ومجلد المزامنة المخفي:** شعار تزامن ثنائي متكافئ (`SVG Logo`) وخزنة مخفية في `C:\ProgramData\TwinSync_Vault` بخصائص الحماية والإخفاء (`Hidden + System`)، مع قاعدة بيانات `twinsync.db` وتهيئة مثبّت ويندوز الموحد (`TwinSync-Pro-Setup-2.2.0.exe`).
2. **السحابة المحلية الموزعة والجسر الافتراضي (`Virtual Peer Gateway Relay`):** بث ومزامنة الحسابات المستقلة (`device_type='mobile'`) وتحديثات رمز `PIN` عبر `PEER_SYNC` و`PEER_ANNOUNCE` و`Delta Sync`، بحيث تتوزع الحسابات والمحادثات والمجلدات على كافة أجهزة الكمبيوتر المتصلة مع **عزل الخصوصية الصارم (`Desktop Privacy Isolation`)** لعدم ظهور محادثات الهواتف الخاصة على شاشات الكمبيوتر المضيفة.
3. **الحسابات الموحدة والتجوال (`PC Account Roaming`) واستعادة الـ `PIN` بدون إنترنت:**
   - إعداد رمز الحماية الشخصي (`Account PIN` من 4 إلى 6 أرقام) من إعدادات الكمبيوتر للدخول به من أي متصفح أو جهاز آخر على الشبكة حتى لو كان الكمبيوتر الأصلي مغلقاً تماماً.
   - إنشاء حساب مستقل جديد من بوابة الويب مع سؤال أمان و**كود استرداد احتياطي لمرة واحدة من 6 رموز** لاستعادة رمز `PIN` المفقود أوفلاين بالكامل.
4. **نافذة الربط بتبويبين وبوابة متجاوبة (`Zero Footprint`):**
   - **ربط سريع (`/?mode=linked&token=...`):** مسح `QR Code` للدخول الفوري بصلاحيات الجهاز الحالي.
   - **بوابة الويب والهاتف الموحدة (`/?mode=portal`):** رابط نصي مباشر و`QR Code` للدخول دون ترك أي بيانات أو ملفات في `localStorage` على الأجهزة الضيفة، مع تصميم متجاوب يتحول تلقائياً على شاشات اللاب توب والكمبيوتر (`>= 768px`) إلى شريط جانبي، عمودين بأسلوب WhatsApp Web، وزر تقسيم الشاشة **`Split View 50/50`**.
5. **تجربة شات بأسلوب WhatsApp الأصلي:**
   - فقاعات رسائل مضبوطة على قدر النص تماماً مع سطر وقت وعلامات قراءة مدمج، وتجميع الرسائل المتتالية لنفس المرسل (تضييق المسافة وإظهار الذيل واسم المرسل في الجروبات بأول رسالة من التجميعة فقط).
   - زر سهم علوي (`⌄`) عند التمرير + الكليك يمين (`Context Menu`) لفتح شريط التفاعلات السريعة وخيارات الرد، التوجيه، النسخ، التعديل، والحذف.
   - تفاعلات لمس أصلية على الهواتف: **السحب للرد (`Swipe-to-Reply`)** بعتبة `50px` و**الضغطة المطوّلة (`400ms`)** لقائمة الإجراءات السفلية.

## أبرز المزايا
- **التوافق والعمل في الخلفية:** مبني على `Electron v22.3.27` مع التثبيت التلقائي في بدء التشغيل (`Auto-Start`)، والتصغير إلى شريط النظام (`System Tray`) مع التنبيهات الصوتية وإشعارات ويندوز الأصلية.
- **اكتشاف تلقائي ومزامنة تفاضلية موزعة:** التعرف على الأجهزة بالـ `UUID` عبر UDP Broadcast و WebSockets، مع مزامنة تفاضلية تلقائية (`Delta Sync`) ونقل مجزأ للملفات والمجلدات (`Chunked Transfer`) ونسخ متوزع للرسائل والحسابات والمجلدات عبر أجهزة الشبكة.
- **خزنة الملفات المخفية والعزل المؤقت (`Temp Shadow Sandbox`):** مجلد مزامنة مخفي (`C:\ProgramData\TwinSync_Vault`)، فتح الملفات بالاسم الحقيقي في مسار مؤقت معزول، الاستبدال الذري الآمن، مؤشر المتواجدين الحقيقي، وحل تعارض التعديل المتزامن (`نسخة متعارضة`).
- **الصلاحيات الهرمية واستعادة كلمة المرور دون إنترنت:** وراثة صارمة من المجلدات الأب، سلة محذوفات معزولة لمدة 30 يوماً، واستعادة كلمة مرور المجلدات عبر سؤال الأمان أو مفتاح الاسترداد الرئيسي (12 رمزاً) من أي جهاز في الشبكة.

## البناء والاختبار عبر Docker

### 1) تشغيل اختبارات التكامل الـ 23 داخل Docker
```bash
docker compose run --rm test
```

### 2) بناء ملف التثبيت `.exe` لنظام ويندوز عبر Docker (باستخدام Wine)
- لمعمارية 64-بت (`x64` — الافتراضية):
  ```bash
  docker compose run --rm win-builder
  ```
- لمعمارية 32-بت (`ia32` لأجهزة Windows 7 القديمة):
  ```bash
  WIN_ARCH=ia32 docker compose run --rm win-builder
  ```
ستجد الملف النهائي وبصمة التحقق في مجلد `release/`.
