# WorkMesh — تطبيق سطح المكتب اللامركزي للشبكات المحلية (P2P LAN Mesh)

تطبيق مؤسسي متكامل يعمل بمعمارية **Peer-to-Peer Mesh & Local-First** دون الحاجة إلى خادم مركزي أو اتصال بالإنترنت، مصمم للعمل على **Windows 7 (SP1)** و **Windows 10/11** وربط الهواتف الذكية داخل الشبكة المحلية.

## أبرز المزايا
- **التوافق والعمل في الخلفية:** مبني على `Electron v22.3.27` مع التثبيت التلقائي في بدء التشغيل (`Auto-Start`)، والتصغير إلى شريط النظام (`System Tray`) مع التنبيهات الصوتية وإشعارات ويندوز الأصلية.
- **اكتشاف تلقائي ومزامنة تفاضلية:** التعرف على الأجهزة بالـ `UUID` عبر UDP Broadcast و WebSockets، مع مزامنة تفاضلية تلقائية (`Delta Sync`) ونقل مجزأ للملفات والمجلدات (`Chunked Transfer`).
- **محادثات متكاملة:** رسائل فردية ومجموعات، الرد المقتبس الشامل، الرسائل الصوتية مع التحكم في السرعة، وإرسال الملفات والمجلدات مباشرة أو من مدير الملفات مع الحفاظ على خصوصية المجلدات المحمية.
- **خزنة الملفات المخفية والعزل المؤقت (`Temp Shadow Sandbox`):** مجلد مزامنة مخفي (`C:\ProgramData\WorkMesh_Vault`)، فتح الملفات بالاسم الحقيقي في مجلد مؤقت معزول، الاستبدال الذري الآمن، مؤشر المتواجدين الحقيقي، وحل تعارض التعديل المتزامن (`نسخة متعارضة`).
- **الصلاحيات الهرمية واستعادة كلمة المرور دون إنترنت:** وراثة صارمة من المجلدات الأب، سلة محذوفات معزولة لمدة 30 يوماً، واستعادة كلمة المرور عبر سؤال الأمان أو مفتاح الاسترداد الرئيسي (12 رمزاً) من أي جهاز في الشبكة.
- **ربط الهاتف عبر `QR Code`:** خادم محلي مع واجهة ويب سريعة (PWA-Style) للوصول للمحادثات والملفات من Android و iOS بدون تثبيت أي تطبيق.

## تحميل ملف التثبيت التلقائي (`.exe`) عبر صفحة المشروع و GitHub Releases

- **صفحة التحميل والشرح الرسمية (GitHub Pages):** **[https://1proo.github.io/localShare/](https://1proo.github.io/localShare/)** *(ثنائية اللغة عربي/إنجليزي ومربوطة تلقائياً بأحدث نسخة في Releases)*.
- **صفحة الإصدارات المباشرة:** **[Releases](https://github.com/1PROO/localShare/releases)**

عند رفع أي تحديث على الفرع الرئيسي (`main` أو `master`) أو إنشاء وسم (`v*`)، يعمل مسار **GitHub Actions** تلقائياً على:
1. التحقق من الكود وبناء الواجهة وتشغيل حزمة اختبارات التكامل الـ 13 على Linux.
2. بناء مثبّت ويندوز الموحّد (`WorkMesh-Setup-<version>.exe` يدعم `x64` و `ia32`) على `windows-2022` مع Node 18 LTS.
3. نشر ملف التثبيت وبصمة `SHA256SUMS.txt` تلقائياً في قسم **[Releases](https://github.com/1PROO/localShare/releases)** وتحديث صفحة GitHub Pages.

## البناء والاختبار عبر Docker

### 1) تشغيل اختبارات التكامل الـ 13 داخل Docker
```bash
docker compose run --rm test
```

### 2) بناء ملف التثبيت `.exe` لنظام ويندوز عبر Docker (باستخدام Wine)
- لمعمارية 64-بت (`x64` — الافتراضية):
  ```bash
  docker compose run --rm win-builder
  ```
- لمعمارية 32-بت (`ia32` لأجهزة Windows 7 القديمة):
  ```bash
  WIN_ARCH=ia32 docker compose run --rm win-builder
  ```
ستجد الملف النهائي وبصمة التحقق في مجلد `release/`.

## البناء اليدوي على نظام Windows

> يُنصح باستخدام **Node.js 18 LTS** وأدوات البناء الخاصة بـ C++ عند الترجمة من المصدر، مع التوافر المباشر للحزم الجاهزة لـ `better-sqlite3@8.7.0` على Electron 22.

```powershell
npm install
npm run rebuild
npm run generate-icons
npm run build
npm run dist:win
```
أو لبناء معمارية محددة:
```powershell
npm run dist:win:x64
npm run dist:win:ia32
```
